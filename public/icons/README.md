# PWA Icons

Add the following PNG icons to this folder for full PWA support:

## Required Icons
- `icon-192x192.png` - Required for Android/Chrome
- `icon-512x512.png` - Required for Android/Chrome splash screen
- `apple-touch-icon-180x180.png` - Required for iOS

## Optional Icons (for better coverage)
- `icon-72x72.png`
- `icon-96x96.png`
- `icon-128x128.png`
- `icon-144x144.png`
- `icon-152x152.png`
- `icon-384x384.png`

## Icon Guidelines
- Use the Pathway "P" logo on the golden yellow (#f5b32b) background
- Icons should be square with rounded corners for maskable icons
- Ensure sufficient padding for maskable icons (safe zone is inner 80%)

## Generate Icons
You can use tools like:
- [PWA Asset Generator](https://github.com/nickvidal/pwa-asset-generator)
- [Real Favicon Generator](https://realfavicongenerator.net/)
- [Maskable.app](https://maskable.app/) for testing maskable icons
